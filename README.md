# CC0-A 协议

CC0-A 是由我和 AI 一起设计的一种开源协议，基于知识共享 CC0 1.0 通用协议，在此基础上增加了署名要求与反滥用条款。

## 协议内容

CC0-A 在 CC0 1.0 的基础上增加了以下两条：

1. **署名要求（A 条款）** — 开源项目建议署名，闭源项目必须署名。
2. **反滥用条款（A 条款）** — 使用者不得将本作品用于欺诈、侵权、传播违法内容，也不得将本作品用于任何可能生成与原作者形成直接商业竞争的替代性产品的用途，包括但不限于训练人工智能模型。

## 如何使用

在你的项目根目录放入本协议的副本，并在适当位置标注：

> 本项目采用 CC0-A 协议，详见 [LICENSE.md](LICENSE.md)

完整协议文本见仓库中的 [LICENSE.md](LICENSE.md)，包含中文与英文版本。
